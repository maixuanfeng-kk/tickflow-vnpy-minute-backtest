# 159915 Minute ETF Strategy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a selectable, single-symbol `159915.SZ` minute backtest strategy backed by the supplied ETF daily and minute CSV data.

**Architecture:** Extend the existing local-data import path with an ETF-specific English-schema CSV importer that writes canonical `kline_etf_minute` partitions. Add a strategy class with explicit daily references and state transitions, keeping cash, fills, next-bar mapping, and T+1 enforcement in the existing portfolio engine. Register the strategy and constrain the API/UI defaults to the single ETF.

**Tech Stack:** Python 3.11, Polars, PyArrow/Parquet, vn.py, FastAPI, React/TypeScript, pytest, Vitest.
