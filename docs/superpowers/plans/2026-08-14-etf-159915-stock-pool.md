# 159915 ETF Stock Pool Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an ETF159915-timed, monthly stock-pool portfolio strategy without changing the existing ETF strategy.

**Architecture:** Run the existing ETF strategy as a read-only shadow pass to produce timestamped events, then run a new stock-pool strategy against monthly pool snapshots and stock minute bars. Keep execution in `MultiSymbolNextBarOpenEngine`; special-case only the new service path for event preparation and monthly pool loading.

**Tech Stack:** Python, vn.py portfolio engine, Polars/Parquet, FastAPI SSE, React/TypeScript, pytest.
