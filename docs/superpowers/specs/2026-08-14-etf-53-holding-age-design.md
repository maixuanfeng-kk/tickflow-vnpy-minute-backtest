# ETF 159915 5.3 持仓天数约束设计

## 目标

5.3 保护只能使用当前仓位实际持有期间形成的连续两日强势组合，不能让买入前已经发生的上涨组合保护新仓位。

## 判定规则

对于候选 5.3 组合中的较早交易日，当前仓位的买入日期必须早于或等于该交易日：

- 检查 `a-2 / a-1` 时，买入日期必须 `<= a-2`。
- 检查 `a-3 / a-2` 时，买入日期必须 `<= a-3`。
- 检查 `a-4 / a-3` 时，买入日期必须 `<= a-4`。
- 检查 `a-5 / a-4` 时，买入日期必须 `<= a-5`。

日期均使用实际交易日日线序列，不使用自然日差值。

## 2025-11-10 验收案例

- 仓位买入日：2025-11-06。
- 候选 5.3 组合：2025-11-05 / 2025-11-06。
- 因 `2025-11-06 > 2025-11-05`，该仓位不能进入这轮 5.3。
- 随后检查 5.2，触发价为 `3.153 * 1.001 = 3.156153`。
- 09:44 分钟收盘价 `3.148 < 3.156153`，应触发 `5_2_before_2_2`。

## 实现范围

- 将持仓买入日期传入卖出保护判断。
- 5.3 候选组合增加上述买入日期过滤。
- 不改变 5.2 公式、5.3 触发价、保护有效期和其他买卖规则。
