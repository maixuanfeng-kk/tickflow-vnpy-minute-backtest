# 早盘放量排序与成交控制设计

## 目标

让“早盘放量组合”的候选排序、建仓/清仓成交口径和期末强制平仓在回测页面可见、可配置，并保证页面设置真实传入专用分钟组合引擎。补齐停牌、涨跌停、T+1 和未成交订单有效期等真实成交约束。

本次只修改早盘放量策略及其专用分钟组合回测路径，不重构通用回测引擎，不处理买入量占成交分钟成交量的比例限制。

## 候选排序

前端增加“候选排序方式”，提供三个值：

- `score`：综合评分。按用户配置的评分权重计算分数并降序排列；同分时依次按同期量比降序、当日涨幅降序、股票代码升序确定顺序。
- `volume_ratio`：同期量比优先。依次按同期量比降序、当日涨幅降序、股票代码升序确定顺序。
- `watchlist_order`：股票池顺序。保持本次回测使用的自选股快照顺序。

候选始终按“逐分钟即时排序”处理。某一分钟产生候选时立即对该分钟候选排序并占用剩余名额；不等待扫描时段结束，也不以之后出现的高排名候选替换已经建立的持仓。

综合评分模式下，用户继续通过现有“评分权重”区域调整同期量比、当日涨幅等权重。非综合评分模式仍保存用户已填写的权重，但本次回测不使用这些权重。

## 建仓与清仓口径

复用现有“建仓口径”和“清仓口径”控件，不新增重复的成交时点控件。早盘分钟策略使用分钟语义：

- `next_minute_open`：信号分钟收盘确认后，按下一分钟开盘价撮合，推荐且作为默认值。
- `signal_minute_close`：按信号分钟收盘价撮合。

前端在早盘策略下显示“下一分钟开盘”和“信号分钟收盘”，不再显示日线策略使用的“次日开盘”和“信号日收盘”。专用分钟 SSE 接口接收并校验两个口径，传入分钟组合配置，结果配置回显实际使用值。

建仓信号对应的买单仅在配置要求的成交分钟有效。该分钟停牌、缺少数据、价格无效、成交量为零或涨停封死时，买单取消；股票之后重新满足入场条件时可再次进入候选排序。

## 仓位分配

早盘策略固定使用等权分配，不展示对该引擎无效的“评分加权仓位”选项。页面直接说明计算公式：

```text
单只目标金额 = 当前总资产 × 最大总仓位 ÷ 最大持仓数
```

候选评分只决定剩余仓位不足时的优先顺序，不改变单只目标金额。

## 期末强制平仓

前端增加“回测末期强制平仓”开关，默认开启，并将值传入专用分钟引擎。

开启时：

- 最后一个回测交易日不再建立新仓，避免期末强平违反 A 股 T+1。
- 已有隔夜持仓在最后可成交分钟尝试平仓，退出原因记为 `end_of_backtest`。
- 停牌、一字跌停、缺少有效价格等情况不能绕过真实成交限制；未能卖出的仓位作为期末未平仓持仓返回。

关闭时：

- 回测结束不生成卖出成交。
- 所有剩余仓位作为期末未平仓持仓返回。

无论开关状态，未平仓持仓均按最后可用分钟收盘价估值并计入最终总资产及浮动盈亏，但不计入完整交易数、胜率、已实现盈亏和按已完成交易计算的统计。

## 固定交易规则

以下规则属于策略或市场真实性约束，只在前端说明，不增加按钮：

- A 分支“突破昨日最高价”使用严格大于 `>`；等于昨日最高价不算突破。
- 候选比较范围固定为逐分钟即时排序。
- A 股持仓遵守 T+1，当日买入不得当日卖出。
- 停牌时不能买卖。
- 一字涨停且无法成交时不能买入；一字跌停且无法成交时不能卖出。

涨跌停判断沿用项目通用回测引擎的市场口径，并在专用分钟引擎中实现等价约束，不增加允许关闭真实性限制的开关。

## 数据流与兼容性

前端将候选排序方式、建仓口径、清仓口径和期末强平开关随早盘策略回测请求发送到 `/backtest/minute-portfolio/stream`。接口校验后构造 `MinutePortfolioConfig`，引擎按配置完成候选排序、撮合与期末处理。结果的 `config` 字段回显这些值，便于复查一次回测实际使用的口径。

旧请求缺少新字段时使用以下兼容默认值：

- 候选排序：同期量比优先，保持旧引擎行为。
- 建仓口径：下一分钟开盘，保持旧引擎行为。
- 清仓口径：下一分钟开盘，保持旧引擎行为。
- 期末强制平仓：开启，保持旧引擎行为。

现有策略参数、基础过滤、评分权重、风控和回测范围继续保留。用户未提交的工作区修改不属于本次交付范围，不清理、不覆盖、不夹带提交。

## 错误处理

接口拒绝未知的排序方式和成交口径，并返回明确的参数错误。期末无法平仓属于可解释的回测结果而非任务错误，应返回未平仓持仓和失败原因。结果必须区分已完成交易与期末未平仓持仓。

## 验证

实现采用测试先行，至少覆盖：

- 三种候选排序方式及综合评分权重变化。
- 候选仅在同一分钟内即时排序。
- 建仓和清仓两种分钟成交口径真实生效。
- 买单在指定成交分钟失败后取消，并允许后续新信号重新参与。
- 期末强平开启、关闭及最后交易日禁止新开仓。
- 期末停牌或一字跌停时保留未平仓持仓并正确估值。
- 一字涨停禁止买入、停牌禁止买卖、T+1 不被期末处理绕过。
- 旧请求缺少新字段时保持兼容默认行为。
- 前端请求参数、策略专属文案、等权公式和无效控件隐藏。
