# Opening-Volume Benchmark Alignment Design

## Goal

Align the native minute-portfolio A-branch semantics with the externally
verified `report.html` benchmark. With the fixed 609-symbol pool, the current
`F:\quant\data\minute_1min_pytdx` snapshot, a 1.5 same-time cumulative-volume
multiple, and a 10-position limit, the 2026-01-06 entries must be exactly:

```text
000737.SZ
000949.SZ
002353.SZ
002851.SZ
002978.SZ
301219.SZ
600711.SH
603799.SH
688127.SH
688556.SH
```

This result must come from the strategy rules. Production code must not contain
a symbol whitelist or a date-specific exception.

## Benchmark Authority and Guarantee Boundary

`report.html` is an externally produced, known-correct result rather than an
output generated by this repository. It is the comparison authority for this
alignment.

The exact first-day guarantee applies to:

- the 609 unique symbols in the user's supplied pool;
- the current local Parquet data snapshot;
- 2026-01-06;
- A branch only;
- previous trading day is bearish;
- same-time cumulative volume ratio is at least 1.5;
- the current minute high is strictly above the previous trading day's high;
- maximum 10 concurrent positions.

Changing the pool, data snapshot, threshold, enabled branches, or capacity can
legitimately change the result.

## Data Semantics

### Daily aggregation

Local daily bars are aggregated from minute rows starting at 09:25. Rows from
09:15 through 09:24 are pre-open virtual quotes and must not determine the
daily open, high, low, close, volume, or moving averages. The 09:25 auction row
is the official daily open and remains part of the daily bar.

This fixes the previous-day candle classification. For example, official daily
data classifies `000737.SZ` as bearish on 2026-01-05 and `300919.SZ` as bullish;
the corrected local aggregation must make the same distinction.

### Same-time cumulative volume

Intraday cumulative volume continues to include the 09:25 auction volume.
For a bar at time `t`, compare the current trading day's cumulative volume
through `t` with the previous trading day's cumulative volume through the same
bar time `t`.

### Breakout

A branch is satisfied when the current minute bar's `high` is strictly greater
than the previous trading day's high. It does not require this bar to be the
first bar that crosses from below. Equality with the previous high is not a
breakout.

## Signal and Execution Timing

The Parquet timestamp labels the start of a one-minute bar. The benchmark
labels the decision at the end of that minute, so displayed signal time is the
source bar timestamp plus one minute. Execution remains at the next available
minute bar open; the economic fill price is not shifted by this display rule.

For 2026-01-06, the expected signal cadence is:

- 09:31: eight symbols;
- 09:32: `002851.SZ`;
- 09:33: `002978.SZ`.

## Unchanged Behavior

This alignment does not change:

- the 609-symbol pool or symbol-normalization rules;
- candidate ordering by volume ratio, current return, then symbol;
- maximum-position enforcement;
- cash-reserve sizing, commission, stamp tax, slippage, or volume participation;
- B and C branch formulas;
- sell rules or next-minute-open execution.

Candidate ordering is intentionally left unchanged because the first day has
no unresolved capacity tie under the corrected trigger cadence. Any later-day
capacity difference will be diagnosed before changing ordering.

## Verification

Tests must first fail against the current implementation and then pass after
the minimum production change. They will prove:

1. 09:15-09:24 rows do not participate in daily aggregation.
2. The 09:25 auction row supplies the daily open and remains in daily volume.
3. The corrected daily candle makes `000737.SZ` bearish and `300919.SZ`
   bullish for the relevant prior day.
4. A bar high above the previous high triggers even when an earlier bar was
   already above it.
5. A bar high equal to the previous high does not trigger.
6. The fixed 609-symbol data-backed regression produces exactly the ten
   benchmark symbols with the 8+1+1 signal cadence.
7. Existing minute-portfolio tests remain green.

The data-backed regression may be marked as an external-data integration test
when the private local dataset is unavailable in another environment; the
small deterministic unit tests remain repository-portable.

## Later-Date Difference Analysis

After the first-day regression is green, run 2026-01-06 through 2026-01-30 and
compare each buy with the benchmark's order-execution audit. Every later-date
difference must be classified with concrete input values as one of:

- prior-day candle classification;
- same-time cumulative-volume ratio;
- strict previous-high breakout;
- position-capacity or deterministic candidate ordering;
- next-minute execution availability or volume participation;
- local minute-data difference from the benchmark source;
- an independently confirmed benchmark rule not yet represented in the engine.

Do not alter production rules merely to force later dates to match. A later
rule change requires evidence, a stated semantic reason, and its own regression
test.
