# 早盘放量组合参数设计

## 目标

让“早盘放量组合（自选股）”作为回测页中的独立策略预设。策略提供默认值，但页面保留通用回测参数，用户可修改后按实际值回测。

## 行为

- 选中早盘放量组合时，初始资金默认设为 10,000,000，最大持仓默认设为 8。
- 初始资金和最大持仓继续使用现有页面输入框，可由用户编辑；不隐藏资金、仓位、成本和成交口径等通用设置。
- 前端将用户当前填写的 `initial_capital`、`max_positions` 和费用参数发送至分钟组合 SSE 接口。
- 后端以收到的 `initial_capital / max_positions` 计算单仓目标金额，并在结果 `config` 中回显实际使用的参数。
- 早盘放量的交易规则仍保持策略固定：昨日同期累计成交量 1.5 倍、09:30--09:59 产生信号、下一分钟开盘成交、2% 止损、前日 MA5 下破卖出与 A 股 T+1。

## 边界

- 不改变 Matrix 日线策略和 vn.py 单标的分钟策略。
- 不把量能阈值、入场时段、止损或 MA5 规则做成可编辑参数。
- 不修改现有自选股快照、手续费、印花税、滑点的语义。

## 验收

1. 选择早盘放量组合后，页面显示初始资金 10,000,000、最大持仓 8，且两者可编辑。
2. 修改任一值并运行时，分钟组合 API 收到该值，结果 `config` 回显相同值。
3. 单仓目标金额等于实际初始资金除以实际最大持仓数。
4. 普通 Matrix/vn.py 回测的默认值与请求不变。
