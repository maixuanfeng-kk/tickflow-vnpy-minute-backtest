# vn.py 分钟回测自选池与布局设计

## 目标

让用户在回测页面直接选择已有的自选股票池（包括按月份保存的分组），并用该股票池运行 vn.py 分钟回测；同时将当前拥挤的页面整理为“左侧配置、右侧结果”的稳定工作区。

## 已确认的交互

- 股票池是回测配置的一部分，选择后替换当前标的，不与旧输入隐式合并。
- 股票池选择器展示现有自选池分组、成员数量，并提供“全部自选”和“手动编辑”入口。
- 选择自选池后，回测请求发送该池的完整成员列表；后端不改变现有回测接口契约。
- 股票池为空时禁止启动回测，并显示明确的校验信息。
- 手动编辑仍可直接输入代码，统一转换为 `000001.SZ` / `600000.SH` 等带交易所后缀格式，避免分钟数据匹配失败。
- 当前日期、策略、参数和运行结果能力保留，但通过分组、折叠和紧凑间距降低纵向占用。

## 布局

采用 A 方案：

- 左侧固定配置栏：股票池选择、成员预览、日期范围、策略选择、核心参数、运行/停止按钮。
- 右侧结果区：运行状态和统计摘要、净值曲线、每日明细/交易/信号/持仓标签页。
- 高级参数放入折叠区域，默认不展开；股票池和日期在回测过程中保持可见。
- 在窄屏下配置栏先于结果区纵向排列，控件不依赖固定宽度溢出。

## 数据流

1. 前端调用已有 `GET /api/watchlist/pools` 获取池清单。
2. 用户选择池后调用已有 `GET /api/watchlist?pool_key=...` 获取成员；`view=all` 继续使用现有全部自选查询。
3. 前端将成员 symbol 列表填入回测请求，并把当前池 key 写入回测页面保存状态。
4. 回测 SSE 仍使用 `/api/backtest/vnpy/stream`；服务端只接收规范化后的 symbol，不新增数据库或数据复制。

## 错误与边界

- 池清单加载失败时保留手动编辑入口，并在选择器内显示错误，不阻塞页面其他配置。
- 选中池没有成员时禁止运行，提示先向该池添加股票。
- 自选中包含 ETF 或没有分钟数据的股票时，回测继续运行有数据的股票；最终结果中保留现有暂停/无数据提示机制。
- 页面恢复上次配置时，如果保存的池 key 已不存在，回退到手动标的文本，不提交过期池成员。

## 测试验收

- 前端测试覆盖池选择后替换 symbol 列表、全部自选查询和空池禁跑。
- 后端已有自选池 API 测试保持通过。
- vn.py 回测 API 使用一个带后缀 symbol 在 2026-01-06 至 2026-01-30 返回进度和完成结果。
- 前端生产构建通过，桌面/窄屏布局无横向溢出。
