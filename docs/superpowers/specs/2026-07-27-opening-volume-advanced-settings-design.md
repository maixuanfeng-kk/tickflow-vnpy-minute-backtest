# 早盘放量高级设置设计

## 目标

让“早盘放量组合”在回测页提供并实际执行五类高级设置：策略参数、基础过滤、评分权重、风控、回测范围。保留 ABC 入场分支、次分钟开盘成交、A 股 T+1 卖出和均线离场等既有分钟策略语义。

## 页面行为

- 早盘策略显示五个页签，不显示通用入场/出场触发器。ABC 分支和均线离场仍由策略参数控制。
- 基础过滤仅展示分钟数据能够无未来函数计算的价格、截至信号分钟累计成交额、板块和 ST 过滤。
- 评分权重提供“同期量比”和“当日涨幅”。默认仍以同期量比为主要顺序，调整权重后只改变同一分钟候选的买入优先级。
- 风控提供止损、止盈、移动止损、回撤止盈和最长持仓。原有均线离场继续生效，风险退出优先于均线退出。
- 回测范围固定为股票。未指定股票时使用全部 TickFlow 自选股；指定股票时使用自选股与指定列表的交集。

## 数据流

前端把策略参数放入 `params`，把基础过滤、评分和风险配置放入 `overrides`，把限定股票放入 `symbols`。`/api/backtest/minute-portfolio/stream` 合并已保存配置和本次请求，构造 `MinutePortfolioConfig`。分钟引擎在每个时间戳按“基础过滤 -> ABC 入场 -> 名额判断 -> 候选超过名额时评分/阈值和截取”选择买入候选，并在持仓可卖后按“风险退出 -> 均线退出 -> 回测结束”处理卖出。

## 兼容性

- 所有新增配置均有不改变既有结果的默认值。
- 未配置评分时继续使用现有的同期量比、当日涨幅、股票代码确定性排序。
- 未指定股票范围时继续使用全部自选股。
- 原 `stop_loss_pct` 参数继续作为早盘策略默认止损；风控页修改止损时更新同一个策略参数，避免两套止损值。

## 验证

- 后端单元测试覆盖过滤、评分排序/阈值、各类风控退出和自选股子集。
- API 测试覆盖 `params`、`overrides`、`symbols` 到 `MinutePortfolioConfig` 的传递。
- 前端测试覆盖早盘策略恰好显示五个页签以及分钟回测请求携带限定股票。
- 运行前端构建和后端分钟组合回归测试，并在浏览器检查五个页签的布局和可编辑状态。
