# 早盘放量分钟组合回测设计

## 目标

在 TickFlow 中新增独立的 A 股分钟组合回测引擎。回测股票池取运行时的自选股快照，初始资金 1,000 万元，最多同时持有 8 只股票。策略仅在 09:30--10:00 建仓，使用昨日同期累计成交量的 1.5 倍作为固定量能门槛。

本期仅交付回测，不做实时扫描、推送、券商下单或日线策略框架重构。

## 策略口径

每只股票、每个交易日的分钟 `t`：

- `current_cumulative_volume[t]`：当日从 09:30 到 `t`（含）的分钟成交量总和。
- `previous_cumulative_volume[t]`：前一交易日从 09:30 到相同时刻 `t`（含）的分钟成交量总和。
- `volume_ratio[t]`：上述两者之比；前日同期累计量为零或缺失时不产生买入信号。
- `today_return[t]`：当前分钟收盘价相对昨日收盘价的涨幅。

仅在 09:30--09:59 的分钟收盘后计算买入候选。这样信号在下一分钟开盘成交，最后一笔允许的买入成交时间为 10:00。

买入候选满足以下任一分支，并都要求 `volume_ratio >= 1.5`：

1. 昨日阴线，且当前分钟首次突破昨日最高价。
2. `3% < today_return < 5%`，且昨日涨幅小于 5%。
3. 昨日上涨，且昨日涨幅小于 5%。

同一股票同一交易日只产生第一次有效买入候选。候选按 `volume_ratio` 降序、`today_return` 降序、股票代码升序排列。

持仓股票的卖出信号在全交易时段判断：当前分钟收盘价不高于实际买入价的 98%，或价格首次下穿截至昨日收盘计算的日线 MA5。A 股 T+1 规则禁止当天买入的股票当天卖出。

## 架构

新增 `backend/app/backtest/minute_portfolio.py`，不修改 `app.vnpy_backtest` 的单股票 CTA 模型，也不改动现有 Matrix 日线策略执行路径。

该模块包含：

- `MinutePortfolioConfig`：股票池快照、日期范围、初始资金、费用与滑点配置；策略常数固定为 8 仓、1.5 倍量能。
- `MinutePortfolioService`：读取批量日线及分钟 K，准备昨日上下文，按交易日/分钟组织事件循环，并输出与现有回测页兼容的结果。
- 纯计算辅助函数：计算同期累计量、判断 A/B/C 入场、判断 MA5 下穿与止损、对候选排序。这些函数不访问仓库或全局状态，供未来实时扫描复用。
- 组合执行状态：共享现金、持仓、同日入场记录、待成交订单和权益曲线。单笔目标仓位为初始资金的八分之一（125 万元），按 100 股整手、下一分钟开盘价、费用和滑点向下取整。

数据加载复用 `TickFlowRepository.get_minute_range()` 以及 `get_daily_batch()`。服务只使用信号时刻之前可见的日线/分钟数据：MA5 取前一交易日行，买卖均在下一分钟开盘成交。

## API

在 `backend/app/api/backtest.py` 新增 `GET /api/backtest/minute-portfolio/stream`。

接口在请求开始时通过现有 `watchlist.list_symbols()` 解析自选股，并将符号列表作为回测配置快照传给服务；后台任务不在执行中重新读取自选股。空自选股、缺少分钟 K 或缺少前一交易日日线时返回明确错误或跳过统计。

接口复用现有 SSE 的 `progress`、`done`、`error` 事件格式、任务去重与重连语义。结果的 `config` 明确标记 `engine: "minute_portfolio"`、`frequency: "1m"` 和自选股快照；交易记录增加信号分支、量能倍数、信号时间及卖出原因。

## 前端

`frontend/src/lib/backtestTask.ts` 的引擎联合类型增加 `minute_portfolio`，并让该引擎连接新 SSE 路径；现有 `matrix` 和 `vnpy` 路径不变。

`frontend/src/pages/backtest/StrategyBacktest.tsx` 增加“早盘放量组合（自选股）”模式。该模式：

- 不允许手工传入股票代码；
- 固定展示初始资金 1,000 万、最大持仓 8、同期量能 1.5 倍；
- 只支持股票资产；
- 沿用日期、手续费与滑点输入；
- 使用已有结果图表和交易明细组件。

## 验证

新增单元测试验证：同期累计量、A/B/C 条件、突破仅触发一次、候选排序、8 仓上限、下一分钟成交、100 股整手、止损、MA5 下穿、T+1、数据缺失处理及自选股快照。

新增 API 测试验证 SSE 事件、空自选股与正常完成。前端至少执行 TypeScript 构建。

## 非目标

- 实时盘中扫描和提醒；
- 飞书推送和券商下单；
- ETF 或 T+0 规则；
- 复用 vn.py 引擎实现多股票共享资金；
- 更改任意现有日线策略的表现或接口。
