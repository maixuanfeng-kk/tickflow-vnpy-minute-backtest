# 159915 分钟交易策略说明

> 标的：159915.SZ（创业板 ETF）
> 行情：原始、不复权的 1 分钟 K 线
> 文档日期：2026-08-11
> 用途：说明策略本身的判断、买卖、状态和资金规则

## 先用一句话理解

这是一套“只做 159915、单仓位、分钟收盘确认、下一分钟开盘成交”的规则：空仓时根据前一交易日的阳阴线、涨跌幅、均线和成交量寻找上涨突破买点；持仓后根据高开回落、强势保护、前低跌破和尾盘走弱等条件卖出；正常卖出当天不再买入，只有 5.4 高开回落卖出后重新站上当日开盘价，才允许当天回补。

## 1. 策略总则

| 项目 | 规则 |
| --- | --- |
| 交易标的 | 仅 `159915.SZ` |
| 行情频率 | 1 分钟 K 线 |
| 价格口径 | 原始价，不复权 |
| 信号价格 | 当前已结束分钟 K 线的收盘价 |
| 成交价格 | 信号出现后的下一根真实分钟 K 线开盘价 |
| 建仓 | 使用当前可用资金的 97% 买入单一标的 |
| 平仓 | 全仓卖出 |
| 持仓限制 | 同一时间只持有一个仓位 |
| 交易制度 | T+1 |
| 持仓期间 | 不判断任何买入条件 |
| 未触发卖出 | 继续持有 |

本文所说的“全仓买入”，是指证券成交金额使用当前可用资金的 97%，不是把佣金包含在这 97% 内。佣金另行从现金中支付，剩余约 3% 作为费用和现金缓冲。

## 2. 信号和成交时点

策略按以下顺序运行：

1. 当前分钟 K 线结束；
2. 使用该分钟 K 线的收盘价判断信号；
3. 信号成立后，在下一根真实分钟 K 线开盘成交；
4. 如果当天没有下一根分钟 K 线，则不产生跨日待成交订单。

`P(t)` 始终表示当前已结束分钟 K 线的**收盘价**，不使用当前分钟的最低价、最高价或盘中瞬时价格代替。

例如，14:25 分钟 K 线收盘满足卖出条件，则在 14:26 分钟 K 线开盘卖出。若 14:13 分钟 K 线最低价碰到触发价，但收盘价没有严格跌破，不产生卖出信号。

标记为 15:00 的分钟 K 线表示 14:59 至 15:00 的价格过程：

- 14:59 分钟线收盘产生的信号，可以在 15:00 分钟线开盘成交；
- 15:00 分钟线结束后，当天没有下一根分钟线，不再产生新信号。

### 2.1 09:30 集合竞价线

09:30 集合竞价 K 线用于：

- 取得当日开盘价；
- 计算包含集合竞价的累计成交量；
- 计算开盘至指定时间的最高价；
- 判断可在 09:31 开盘成交的信号。

因此，09:31 是当天第一笔可成交时间。

### 2.2 判断与成交窗口

| 规则 | 信号判断时间 | 对应成交时间 |
| --- | --- | --- |
| 上午买入总体窗口 | 09:30 至 11:29 | 09:31 至 11:30 |
| 4.1.1、4.1.2、4.2.1 | 最早 09:31 判断 | 最早 09:32 成交 |
| 4.2.2 | 最早 09:32 判断 | 最早 09:33 成交 |
| 4.2.3 | 最早 09:30 判断 | 最早 09:31 成交 |
| 尾盘买入 | 14:45 至 14:59 | 14:46 至 15:00 |
| 5.1 常规卖出 | 09:30 至 14:54 | 09:31 至 14:55 |
| 5.5 尾盘卖出 | 14:30 至 14:59 | 14:31 至 15:00 |
| 5.2、5.3、5.4、5.6 | 09:30 至 14:59 | 09:31 至 15:00 |

4.1.1、4.1.2 和 4.2.1 需要先取得截至 09:31 的早盘最高价，因此最早在 09:31 分钟线结束时判断。4.2.2 需要取得截至 09:32 的最高价，因此最早在 09:32 分钟线结束时判断。

## 3. 符号和计算公式

设当前交易日为 `a`，当前已结束的信号分钟为 `t`。文中的“昨日”均指上一交易日，不是上一自然日。

| 符号 | 含义 |
| --- | --- |
| `P(t)` | 当前已结束分钟 K 线的收盘价 |
| `O(a)` | a 日开盘价，包含集合竞价 |
| `O(a-1)` | a-1 日开盘价 |
| `H(a-1)` | a-1 日最高价 |
| `L(a-1)` | a-1 日最低价 |
| `C(a-1)` | a-1 日收盘价，即 a 日昨收 |
| `C(a-2)` | a-2 日收盘价 |
| `C(a-3)` | a-3 日收盘价 |

### 3.1 涨跌幅

涨幅和涨跌幅均为有符号值：

```text
涨跌幅 = (当前价 - 基准价) / 基准价

a 日盘中涨跌幅 = (P(t) - C(a-1)) / C(a-1)

a-1 日涨跌幅 = (C(a-1) - C(a-2)) / C(a-2)

a-1 日开盘涨跌幅 = (O(a-1) - C(a-2)) / C(a-2)

a-1 日最高点涨幅 = (H(a-1) - C(a-2)) / C(a-2)
```

特别注意：`a-1 日开盘涨跌幅` 的分母是 `C(a-2)`，不是 `C(a-1)`。

### 3.2 实体涨跌幅

```text
实体涨跌幅 = (当前价 - 当日开盘价) / 当日开盘价

a 日盘中实体涨跌幅 = (P(t) - O(a)) / O(a)

a-1 日实体涨跌幅 = (C(a-1) - O(a-1)) / O(a-1)
```

### 3.3 跌幅

跌幅使用与涨跌幅相反的分子顺序，下跌时通常为正：

```text
跌幅 = (基准价 - 当前价) / 基准价

a 日盘中跌幅 = (C(a-1) - P(t)) / C(a-1)

a-1 日跌幅 = (C(a-2) - C(a-1)) / C(a-2)

a-1 日相对 a-3 日跌幅 = (C(a-3) - C(a-1)) / C(a-3)
```

### 3.4 实体跌幅

```text
实体跌幅 = (当日开盘价 - 当前价) / 当日开盘价

a 日盘中实体跌幅 = (O(a) - P(t)) / O(a)

a-1 日实体跌幅 = (O(a-1) - C(a-1)) / O(a-1)
```

### 3.5 最低价至收盘涨幅

```text
a-1 日最低价至收盘涨幅
= (C(a-1) - L(a-1)) / L(a-1)
```

## 4. 阴阳线和边界

| 类型 | 判断条件 |
| --- | --- |
| 阳线，包括假阳线 | `收盘价 > 开盘价` |
| 阴线，包括假阴线 | `收盘价 < 开盘价` |
| 十字线 | `收盘价 == 开盘价` |

假阳线即使相对前收下跌，只要收盘价高于开盘价，仍按阳线处理。假阴线即使相对前收上涨，只要收盘价低于开盘价，仍按阴线处理。

十字线不进入 4.1 阳线普通规则，也不进入 4.2 阴线普通规则。已经从前一日延续的 4.2.3 独占状态仍继续有效，尾盘买入规则也不受十字线分类影响。

所有边界统一采用以下口径：

- “突破、超过、大于、跌破”均为严格 `>` 或 `<`；
- 所有卖出条件都要求 `P(t)` 严格跌破触发价，等于触发价时不卖；
- `(x, y)` 表示开区间，不包含两端；
- 只有明确写 `>=` 或 `<=` 时才包含等于；
- 落在规则未覆盖边界上的数值，不自动归入相邻区间。

例如，4.2.1 的 `(0.5%, 1.5%)` 不包含 0.5% 和 1.5%，4.2.2 的 `(0, 0.5%)` 也不包含 0.5%，所以刚好 0.5% 不属于这两条规则。

## 5. 公共盘中特征

### 5.1 开盘至 09:31 最高价

```text
H09:31 = 09:30 集合竞价线至 09:31 分钟线之间的最高价

突破条件：P(t) > H09:31
```

### 5.2 开盘至 09:32 最高价

```text
H09:32 = 09:30 集合竞价线至 09:32 分钟线之间的最高价

突破条件：P(t) > H09:32
```

### 5.3 同期累计成交量

在当前信号分钟 `t` 比较：

```text
a 日 09:30 集合竞价至 t 的累计成交量
>
1.2 × a-1 日 09:30 集合竞价至相同分钟的累计成交量
```

只使用信号分钟及以前的数据，不读取下一分钟成交 K 线的成交量。

### 5.4 动态 MA5

- 均线使用不复权收盘价；
- 判断某个已完成交易日时，MA5 包含该日自身收盘价；
- 4.2.3 的均线条件只使用 MA5，不使用 MA10。

## 6. 买入规则

### 6.1 买入总约束

1. 只有空仓时才判断买入；
2. 持仓期间完全跳过所有买入判断；
3. 买入证券成交金额为当前可用资金的 97%，佣金另付；
4. 除 5.4 当日回补外，当天卖出后不再判断其他买入；
5. 上午买入成交时间为 09:31 至 11:30；
6. 尾盘在 14:45 至 14:59 判断，下一分钟开盘成交；
7. 4.2.3 前置条件一旦成立，当天具有独占性，屏蔽所有其他买入规则，包括尾盘规则。

### 6.2 规则 4.1：a-1 日为阳线

公共前置条件：

```text
C(a-1) > O(a-1)
```

#### 6.2.1 规则 4.1.1

分类条件：

```text
a-1 日最高点涨幅 - a-1 日收盘涨幅 > 0.3%
```

也就是：

```text
(H(a-1) - C(a-2)) / C(a-2)
-
(C(a-1) - C(a-2)) / C(a-2)
> 0.3%
```

买入信号要求同时满足：

```text
P(t) > H(a-1)
且
P(t) > H09:31
```

#### 6.2.2 规则 4.1.2

分类条件：

```text
a-1 日最高点涨幅 - a-1 日收盘涨幅 <= 0.3%
```

买入信号要求同时满足：

```text
a 日盘中实体涨幅 > 0.3%
且
a 日同期累计成交量 > 1.2 × a-1 日同期累计成交量
且
P(t) > H09:31
```

### 6.3 规则 4.2：a-1 日为阴线

普通规则前置条件：

```text
C(a-1) < O(a-1)
```

4.2.3 是本组的高优先级特殊规则，先于 4.2.1 和 4.2.2 判断。

#### 6.3.1 规则 4.2.1

分类条件：

```text
a-1 日开盘涨跌幅 - a-1 日收盘涨跌幅
位于 (0.5%, 1.5%)
```

买入信号要求同时满足：

```text
P(t) > O(a-1)
且
P(t) > H09:31
```

#### 6.3.2 规则 4.2.2

分类条件：

```text
a-1 日开盘涨跌幅 - a-1 日收盘涨跌幅
位于 (0, 0.5%)
```

买入信号要求同时满足：

```text
a 日盘中实体涨跌幅 > 0.5%
且
P(t) > H09:32
```

### 6.4 规则 4.2.3：阴线后的高优先级买入状态

4.2.3 包含两个互斥等级：

```text
4.2.3-1 > 4.2.3-2 > 其他上午买入规则 / 尾盘买入规则
```

只要某条 4.2.3 前置条件成立，即使当天最终没有突破买入点，也不再判断其他买入规则。

#### 6.4.1 公共前置条件

候选日 a 开始前必须同时满足：

```text
a-2、a-1 连续两个交易日的收盘价
均严格低于各自动态 MA5

且

(MA5(a-1) - C(a-1)) / MA5(a-1) > 1.5%

且

(C(a-2) - C(a-1)) / C(a-2) > 1.5%
```

该特殊状态按交易日志对齐口径识别，不额外要求 `a-1` 为阴线，也不检查 MA10。

#### 6.4.2 规则 4.2.3-1

在公共前置条件基础上，额外要求：

```text
(C(a-3) - C(a-1)) / C(a-3) > 3%
```

触发价为 `C(a-2)`，在 a 日和 a+1 日都按以下条件买入：

```text
P(t) > C(a-2)
```

如果 a 日没有突破，a+1 日继续使用同一 `C(a-2)`。如果 a+1 日自身形成新的 4.2.3-1 前置条件，则重新计算触发价并重新开始两日周期。

#### 6.4.3 规则 4.2.3-2

当 4.2.3-1 不成立、但公共前置条件成立时，使用 4.2.3-2。

买入信号要求同时满足：

```text
P(t) > O(a-1)
且
a 日盘中涨跌幅 > 0.5%
```

如果 a 日没有突破，4.2.3-2 在 a+1 日继续使用同一 `O(a-1)`；如果 a+1 日形成新的前置条件，则按状态更新规则决定是否替换。

#### 6.4.4 状态更新

- 同级前置条件再次成立时，更新触发价并重置周期；
- 更高级条件成立时，切换到更高级规则；
- 低级条件不能覆盖当前高级状态；
- 4.2.3 独占状态存在时，不判断 4.1、4.2 普通买入和尾盘买入。

### 6.5 尾盘买入

尾盘在 14:45 至 14:59 使用当前分钟收盘价判断，下一分钟开盘成交。以下三条为并列条件，任意一条成立即可买入。若 4.2.3 独占状态存在，则三条都不判断。

#### 6.5.1 尾盘规则 1

前置条件：

```text
a-1 日实体跌幅位于 (0.5%, 1%)
```

买入信号：

```text
a 日盘中实体涨幅 >= 0.5%
且
a 日盘中实体涨幅 > a-1 日实体跌幅
```

#### 6.5.2 尾盘规则 2

前置条件：

```text
a-1 日实体跌幅 >= 1%
```

买入信号：

```text
a 日盘中实体涨幅 >= a-1 日实体跌幅 - 0.2%
```

例如，a-1 日实体跌幅为 1.2%，则 a 日盘中实体涨幅达到 1.0% 即满足条件。

#### 6.5.3 尾盘规则 3

前置条件：

```text
a-1 日实体涨跌幅位于 (-1%, 1.5%)
```

买入信号要求同时满足：

```text
a 日盘中实体涨幅 > 0.5%
且
a 日盘中实体涨幅 > abs(a-1 日涨跌幅)
且
a 日盘中涨跌幅 < 2%
```

第二项比较的是 a-1 日相对 a-2 日收盘价的涨跌幅绝对值，不是 a-1 日实体涨跌幅的绝对值。

## 7. 卖出规则

### 7.1 卖出总约束和优先级

1. 只有持仓时才判断卖出；
2. 任一有效卖出条件成立后，全仓卖出；
3. 所有卖出信号均使用当前已结束分钟的收盘价 `P(t)`；
4. 所有卖出触发价都要求严格跌破，等于触发价时不卖；
5. 5.2 或 5.3 保护期内不执行 5.1、5.5 和 5.6；
6. 5.4 在 5.2 或 5.3 保护期内仍可优先执行。

卖出优先级：

```text
5.4 > 5.3 > 5.2 > 5.1 / 5.5 / 5.6
```

5.1、5.5 和 5.6 同时成立时，结果都是全仓卖出，不再区分三者内部优先级。

### 7.2 规则 5.1：常规卖出

5.1 在 09:30 至 14:54 判断，对应 09:31 至 14:55 成交。

#### 7.2.1 规则 5.1.1

前置条件：

```text
a-1 日涨跌幅位于 (0.5%, 1.3%)
```

卖出信号：

```text
P(t) < C(a-2)
```

#### 7.2.2 规则 5.1.2

前置条件：

```text
a-1 日涨跌幅位于 (0, 0.5%)
且
a-1 日最低价至收盘涨幅位于 (0, 1.3%)
```

卖出信号：

```text
P(t) < L(a-1)
```

这里比较的是当前分钟**收盘价**，不是当前分钟最低价。若最低价等于 `L(a-1)`、但收盘价未严格低于 `L(a-1)`，不卖出。

#### 7.2.3 规则 5.1.3

前置条件：

```text
a-1 日涨跌幅位于 (0, 0.5%)
且
a-1 日最低价至收盘涨幅 > 1.3%
```

触发价：

```text
T5.1.3 = C(a-1) - (C(a-1) - L(a-1)) × 2 / 3
```

卖出信号：

```text
P(t) < T5.1.3
```

### 7.3 规则 5.2：单日强势后的两日保护

候选日 a 开始前，以下任意一项成立则进入 5.2：

```text
a-1 日实体涨幅 > 1.3%
或
a-1 日涨幅 > 1.3%
```

触发价：

```text
T5.2 = L(a-1) × 1.001
```

在 a 日和 a+1 日均按以下条件卖出：

```text
P(t) < T5.2
```

如果没有跌破则继续持有。若 a+1 日没有形成新的保护条件，a+2 日恢复常规规则。

5.2 动态更新规则：

- 保护期内再次形成 5.2 条件时，使用最新的 a-1 日最低价重算触发价，并重新开始两日周期；
- 形成更高等级的 5.3 条件时，切换至 5.3；
- 低等级条件不能覆盖 5.2；
- 5.4 可优先执行，但不会暂停、延长或清除原 5.2 日历周期。

### 7.4 规则 5.3：连续实体上涨后的四日保护

候选日 a 开始前必须同时满足：

```text
a-2 日实体涨幅 > 1.3%
且
a-1 日实体涨幅 > 1.3%
```

触发价：

```text
T5.3 = C(a-2)
```

在 a、a+1、a+2、a+3 日均按以下条件卖出：

```text
P(t) < T5.3
```

若四个保护日内始终没有跌破，则继续持有，a+4 日恢复常规规则。

5.3 动态更新和消费规则：

- 保护期内再次形成新的 5.3 条件时，使用最新 `C(a-2)` 重置触发价，并重新开始至新 a+3 的四日周期；
- 低等级条件不能覆盖 5.3；
- 5.4 可优先执行，但不会暂停、延长或清除当前 5.3 日历周期；
- 只有 5.3 信号实际完成全仓卖出成交后，这一轮 5.3 才被标记为已消费；
- 已消费的 5.3 不得作用于之后新建立的仓位；
- 后续只有再次形成新的“连续两个交易日实体涨幅都严格大于 1.3%”条件，才能建立新一轮 5.3。

因此，某一轮 5.3 在 9 月 2 日完成全仓卖出后，不能在没有新连续两日强势条件的情况下，再作用于 9 月 4 日建立的新仓位。

### 7.5 规则 5.4：高开回落卖出和当日回补

5.4 具有单日最高优先级，在 09:30 至 14:59 判断，下一分钟开盘成交。

高开前置条件：

```text
(O(a) - C(a-1)) / C(a-1) > 2%
```

卖出信号：

```text
(O(a) - P(t)) / O(a) > 1%
```

即当前分钟收盘价相对当日开盘价回落超过 1% 时，全仓卖出。

因 5.4 卖出后，当天唯一允许的买入是 5.4 回补：

```text
P(t) > O(a)
```

满足后，下一分钟开盘使用 97% 可用资金买回。因执行 T+1，当日回补的份额当天不能再次卖出。

5.4 在 5.2 或 5.3 保护期内仍优先执行，但原保护周期继续按交易日日历推进，不因 5.4 卖出或回补而暂停、延长或清除。

### 7.6 规则 5.5：14:30 后的实体下跌卖出

5.5 从 14:30 分钟线结束时开始判断，最晚 14:59 判断、15:00 成交。

卖出信号要求同时满足：

```text
a 日盘中实体跌幅 > 1%
且
a 日盘中实体跌幅 > a-1 日实体涨幅
且
P(t) < C(a-1)
且
a-1 日涨幅 > 0
```

第二项直接使用有符号的 a-1 日实体涨幅。若 a-1 日是假阴线，实体涨幅为负数，但相对前收仍上涨，则 a 日实体跌幅大于 1% 时通常也自然大于该负数。

5.2 或 5.3 保护期内不执行 5.5。

### 7.7 规则 5.6：双低点或当日跌幅强制卖出

除 5.2、5.3 保护期外，以下任意一项成立即全仓卖出：

```text
P(t) < min(L(a-1), L(a-2))
```

或者：

```text
a 日盘中跌幅 > 1%
```

其中：

```text
a 日盘中跌幅 = (C(a-1) - P(t)) / C(a-1)
```

两项都是严格跌破或严格大于，等于边界时不卖。

### 7.8 卖出后的当日买入限制

任意卖出完成后，当天关闭普通上午买入、4.2.3 和尾盘买入。

唯一例外是 5.4 回补，且必须同时满足：

- 当天确实因 5.4 完成卖出；
- 卖出后，某个已结束分钟的收盘价严格高于当日开盘价；
- 下一分钟开盘使用 97% 可用资金买回；
- 其他原因卖出后，即使价格重新高于开盘价，当天也不能买回。

## 8. 每分钟决策顺序

### 8.1 当前有持仓

1. 先判断 5.4；
2. 若 5.4 不成立，判断是否处于有效的 5.3 保护状态；
3. 若没有 5.3，判断是否处于有效的 5.2 保护状态；
4. 若没有 5.2 或 5.3，根据时间窗口判断 5.1、5.5 和 5.6；
5. 任一有效卖出条件成立，生成全仓卖出信号；
6. 均不成立，继续持有。

### 8.2 当前空仓

1. 如果当天已经卖出，除 5.4 回补外停止所有买入判断；
2. 判断是否存在 4.2.3-1 独占状态；
3. 若不存在，判断是否存在 4.2.3-2 独占状态；
4. 只要存在 4.2.3 独占状态，就只判断对应突破条件；
5. 若不存在 4.2.3 独占状态，在上午窗口按昨日阴阳线判断 4.1 或 4.2 普通规则；
6. 在尾盘窗口判断三条尾盘买入规则；
7. 任一允许的买入条件成立，生成 97% 可用资金买入信号。

## 9. 仓位和交易制度

### 9.1 仓位计算

买入目标证券成交金额：

```text
目标证券成交金额 = 当前可用资金 × 97%
```

实际买入数量按 ETF 最小交易单位向下取整。97% 只计算证券成交金额，买入佣金在证券成交金额之外另行扣除。

例如，可用资金为 100,000 元、成交价为 10 元且暂不考虑整手以外的误差：

```text
证券成交金额 = 100,000 × 97% = 97,000 元
佣金 = 97,000 × 佣金率，且不低于最低佣金
剩余现金 = 100,000 - 97,000 - 佣金
```

卖出时全仓卖出可卖数量，卖出到账现金为成交金额扣除佣金和适用税费后的净额。

### 9.2 T+1

- 当日买入的份额当天不能卖出；
- 普通持仓从下一交易日起可以按卖出规则卖出；
- 5.4 当日回补份额同样受 T+1 限制，当天不能再次卖出。
